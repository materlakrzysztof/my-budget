# Dashboard month-over-month comparison

Let the user compare the current month's spending against the previous month
(total, and per-category where available) on the dashboard. When the previous
calendar month has no spend, the comparison is hidden rather than shown as a
misleading change from zero. Traces to roadmap S-09 / PRD FR-018 / US-05.
Prerequisite S-08 (monthly-dashboard) is shipped.
