# Polish UI

Present the entire user-facing UI in Polish, with all strings externalized to a
lightweight message-key layer so another language could be added later without a
rewrite. No language-switcher UI is in scope (Polish is the only shipped
language). Traces to roadmap S-11 / PRD FR-020.
